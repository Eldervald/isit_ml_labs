## Установка и настройка Ruff в VS Code

Ruff — это быстрый линтер и форматтер для Python, написанный на Rust. Он объединяет функционал Flake8, Black, isort и других инструментов.

### Шаг 1: Установка расширения

1. Откройте VS Code
2. Перейдите в раздел расширений (Ctrl+Shift+X или Cmd+Shift+X)
3. Введите в поиске "Ruff"
4. Установите расширение от автора **Astral** (Publisher: Astral)

### Шаг 2: Настройка расширения

Откройте настройки (Ctrl+, или Cmd+,), найдите "ruff" или добавьте следующие настройки в ваш `settings.json`:

```json
"[python]": {
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
        "source.fixAll.ruff": "explicit",
        "source.organizeImports.ruff": "explicit"
    }
},
"ruff.lint.enable": true,
"ruff.format.enable": true
```

### Шаг 3: Проверка работы

После настройки:
1. Откройте любой Python файл
2. Попробуйте сохранить файл (Ctrl+S или Cmd+S)
3. Ruff автоматически отформатирует код и исправит некоторые проблемы

### Дополнительные команды

Вы можете использовать палитру команд (Ctrl+Shift+P или Cmd+Shift+P) для:
- `Ruff: Format Document` — форматировать документ
- `Ruff: Fix All` — исправить все проблемы
- `Ruff: Organize Imports` — отсортировать импорты

### Конфигурация через `pyproject.toml`

Ruff уже настроен в этом проекте через `pyproject.toml`. Если вы хотите изменить настройки форматирования или линтинга, отредактируйте секцию `[tool.ruff]` в этом файле.

## Установка `uv`

Для начала работы с `uv`, его необходимо установить. Вы можете установить `uv` следуя инструкциям из официальной документации:

```
https://docs.astral.sh/uv/getting-started/installation/
```

После установки убедитесь, что `uv` доступен в вашей системе:

```bash
uv --version
```

## Настройка проекта

1. **Склоньте данный репозиторий с командой `git` (установите его, если у вас его нет), после чего перейдите в директорию проекта:**

   ```bash
   git clone https://github.com/Eldervald/isit_ml_labs.git
   cd isit_ml_labs
   ```

2. **Синхронизируйте проект с помощью `uv`:**

   ```bash
   uv sync
   ```

   Эта команда создаст виртуальное окружение и установит все необходимые зависимости для проекта. По умолчанию оно будет расположено в директории `.venv`.

3. **Активируйте виртуальное окружение:**

   - На Unix-системах (Linux/macOS):

     ```bash
     source .venv/bin/activate
     ```

   - На Windows:

     ```bash
     .venv\Scripts\activate
     ```
     Если не сработало, попробуйте:
     ```bash
     .venv\Scripts\activate.ps1
     ```

## Запуск проекта

1. **Запуск Python скрипта:**

   Если у вас есть Python скрипт, например `main.py`, вы можете запустить его с помощью:

   ```bash
   python main.py
   ```

   Убедитесь, что виртуальное окружение активировано.

2. **Запуск Python скрипта с использованием `uv`:**

   ```bash
   uv run main.py
   ```

   Эта команда автоматически активирует виртуальное окружение и запускает проект.

3. **Запуск тестов:**

   Если вы используете `pytest` для тестирования (а именно его вы и будете использовать), вы можете запустить все тесты с помощью:

   ```bash
   uv run pytest
   ```
   
   Можно тестировать отдельные файлы тестов или директории, например запустим тесты для самой первой задачи:

   ```bash
   uv run pytest lab1-python-intro\a_hello_world
   ```

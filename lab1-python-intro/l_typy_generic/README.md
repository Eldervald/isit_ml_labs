## VECTOR ITERATOR

`typing` `generic` `__iter__` `__next__` `iterator` `iterable` `StopIteration`

### Условие

Нужно реализовать и аннотировать два класса: `Vector` и `VectorIterator`.

Класс `Vector[T]` — это Generic-контейнер для хранения элементов одного типа. Он должен поддерживать:

**Базовые операции:**
- Создание вектора из списка элементов
- Получение длины (`len()`)
- Доступ к элементам по индексу (включая отрицательные индексы)
- Добавление элементов в конец (`append()`)
- Добавление нескольких элементов (`extend()`)
- Итерацию по элементам (цикл `for`)
- Строковое представление (`str()` и `repr()`)

**Математические операции:**
- Сложение векторов (`v1 + v2`)
- Вычитание векторов (`v1 - v2`)
- Умножение на скаляр (`v * scalar` и `scalar * v`)
- Скалярное произведение (`v1.dot(v2)`)

Класс `VectorIterator[T]` — это итератор для `Vector`. Он должен:
- Хранить ссылку на вектор и текущую позицию
- Поддерживать протокол итератора (методы `__iter__` и `__next__`)
- Возвращать следующий элемент при каждом вызове `__next__`
- Вызывать `StopIteration` когда элементы закончились

Как ограничивать входные типы — смотрите в тестах.


### Про задачу

* Здесь вам нужно узнать, как создавать [классы-генерики](https://mypy.readthedocs.io/en/latest/generics.html)
* Нужно реализовать [протокол итератора](https://docs.python.org/3/tutorial/classes.html#iterators):
  - `__iter__` у вектора возвращает новый итератор
  - `__iter__` у итератора возвращает сам итератор (`self`)
  - `__next__` возвращает следующий элемент или вызывает `StopIteration`
* TypeVar для генериков нужно сделать [с ограничениями](https://mypy.readthedocs.io/en/latest/generics.html#type-variables-with-value-restriction)
* Важно понимать разницу между **iterable** и **iterator**:
  - Iterable (контейнер) имеет `__iter__` и возвращает новый итератор при каждом вызове
  - Iterator имеет и `__iter__`, и `__next__`, при этом `__iter__` возвращает `self`
* В тестах проверяется:
  * Что вы везде навесили аннотации типов
  * Что mypy проходит для числовых типов и падает для строк
  * Что итераторы работают независимо (несколько итераторов не влияют друг на друга)
  * Что протокол итератора реализован корректно (`for` циклы, `iter()`, `next()`, `StopIteration`)

### Пример использования

```python
# Создание вектора с целыми числами
v = Vector[int]([1, 2, 3])

# Доступ к элементам
print(len(v))        # 3
print(v[0])          # 1
print(v[-1])         # 3

# Добавление элементов
v.append(4)
v.extend([5, 6])
print(len(v))        # 6

# Итерация через for
for item in v:
    print(item)      # 1, 2, 3, 4, 5, 6

# Итерация через iter/next
it = iter(v)
print(next(it))      # 1
print(next(it))      # 2

# Несколько независимых итераторов
it1 = iter(v)
it2 = iter(v)
print(next(it1))     # 1
print(next(it2))     # 1 (не зависит от it1)

# Математические операции
v1 = Vector[int]([1, 2, 3])
v2 = Vector[int]([4, 5, 6])

print(v1 + v2)       # Vector([5, 7, 9])
print(v1 - v2)       # Vector([-3, -3, -3])
print(v1 * 2)        # Vector([2, 4, 6])
print(3 * v2)        # Vector([12, 15, 18])
print(v1.dot(v2))    # 32 (1*4 + 2*5 + 3*6)

# Цепочки операций
result = (v1 + v2) * 2
print(list(result))  # [10, 14, 18]
```

Воспринимайте тесты, как условия, которым должен удовлетворять интерфейс ваших функций и классов.

## TRY / EXCEPT / FINALLY + ASSERT

`try` `except` `finally` `assert`

### Условие

В этой задаче вы научитесь обрабатывать ошибки с помощью `try/except/finally`
и использовать `assert` для проверки предусловий и написания тестов.

Предметная область -- [CTR](https://ru.wikipedia.org/wiki/CTR_(Интернет)).
Функция `ctr` ниже содержит несколько багов, которые вам нужно научиться
обнаруживать и обходить.

#### test_check_ctr

Реализовать функцию `test_check_ctr`, которая проверяет, что функция `ctr`
возвращает корректный результат.
* Если `ctr(clicks, shows) == expected_result` -- ничего не делает.
* Если нет -- поднимает `AssertionError` с сообщением "Wrong ctr calculation"

Функция `ctr` специально написана с багами, которые ваш микротест
должен отловить.

##### Пример

```python
>>> test_check_ctr(2, 2, 1.0)      # ok, ничего не делает
>>> test_check_ctr(1, 2, 0.5)      # баг! 0 вместо 0.5
AssertionError: Wrong ctr calculation
```

#### safe_ctr

Реализовать функцию `safe_ctr`, которая безопасно вычисляет CTR,
обрабатывая возможные ошибки.

Требования:
1. Внутри `try` проверьте через `assert`, что `clicks >= 0`.
   Если нет -- поднимите `AssertionError` с сообщением
   "Clicks must be non-negative".
2. Вызовите `ctr(clicks, shows)` и верните результат как `float`.
3. Если `ctr` поднимает `ValueError` (например, при отрицательных shows),
   верните `-1.0`.
4. Если `ctr` поднимает `ZeroDivisionError` (при shows == 0),
   верните `0.0`.
5. В блоке `finally` всегда добавляйте строку `"done"` в `log`.

##### Пример

```python
>>> log = []
>>> safe_ctr(2, 2, log)
1.0
>>> log
['done']

>>> log = []
>>> safe_ctr(5, -1, log)     # ctr поднимает ValueError
-1.0
>>> log
['done']

>>> log = []
>>> safe_ctr(10, 0, log)     # ctr поднимает ZeroDivisionError
0.0
>>> log
['done']

>>> log = []
>>> safe_ctr(-1, 5, log)     # assert не проходит
AssertionError: Clicks must be non-negative
>>> log                       # finally всё равно отработал!
['done']
```

### Про задачу

#### Предметная область

[CTR](https://ru.wikipedia.org/wiki/CTR_(Интернет)) -- самая упоминаемая метрика в рекламе.
Например, вы серфите интернет и видите рекламу ШАД 4 раза. На 4-й раз -- кликаете.
Тогда для вас CTR этой рекламы -- 0.25.

Метрику можно интерпретировать как "вероятность клика по рекламе". Поэтому в Яндексе часто
опускают конвертацию в %.

Кликов может оказаться больше чем показов.
Например, вы увидели баннер 1 раз и 2 раза по нему случайно кликнули.
В этом случае повторный клик часто помечают легким фродом, и
для расчетов используют только 1-й клик.

#### try / except / finally

Конструкция `try/except/finally` позволяет обрабатывать ошибки в Python:

```python
try:
    # код, который может вызвать ошибку
    result = risky_operation()
except ValueError:
    # обработка конкретной ошибки
    result = default_value()
except ZeroDivisionError:
    # обработка другой ошибки
    result = 0
finally:
    # этот блок ВСЕГДА выполняется,
    # даже если произошла ошибка
    cleanup()
```

Ключевые моменты:
* `except ValueError` -- ловит только `ValueError`. Используйте
  конкретные типы исключений, а не голый `except:`.
* Несколько блоков `except` обрабатывают разные типы ошибок по-разному.
* `finally` выполняется **всегда** -- и при успешном выполнении,
  и при ошибке. Это удобно для очистки ресурсов (закрытие файлов,
  логирование и т.д.).

#### assert

Конструкция `assert` проверяет условие и поднимает `AssertionError`,
если оно ложно:

```python
assert x > 0, "x must be positive"
# эквивалентно:
if x <= 0:
    raise AssertionError("x must be positive")
```

Используйте `assert` для:
* проверки предусловий (sanity checks) при разработке
* написания простых тестов

> **Важно!** Не используйте `assert` для обработки реальных ошибок
> в продакшен-коде, потому что проверки можно отключить флагом `-O`.

### Уточнения

* Используйте `float()` для преобразования результата `ctr` в `float`
* Блок `finally` должен добавлять `"done"` в `log` ровно один раз
  за вызов функции
* `AssertionError` от `assert clicks >= 0` **не нужно** ловить в
  `except` -- пусть он пробрасывается выше. Но `finally` всё равно
  должен отработать
